# 视觉证据判断研究

CHIIR 2027 研究的参与者网页。沿用 ScopeProof 的部署方式：GitHub Pages 提供静态页面，Supabase 保存受会话令牌保护的研究记录。

- 独立首页必填回响用户ID，允许粘贴，用于审核匹配和报酬。
- 每人 4 道练习＋36 道正式题，三个条件各 12 题。
- 每题选择正确／错误和 1–7 确定程度；最后 3 条案例回顾均须填写回答；记不清时可如实写明。
- 网站自动分配冻结编号，每题自动保存；服务器确认完成后返回回响任务202610118100。末尾不收完成码、不强制等待。
- `?preview=1` 为不上传的预览；本机默认预览；`?preview=1&cloud-test=1` 仅写软件测试记录。
- 正式答案、参与者原始记录、数据库密码和管理密钥不在本仓库。
- 36 个初始编号按服务器先到顺序依次分配；退出记录保留，补招需研究者另行安排。编号不等于身份验证。

`site/index.html` 是冻结材料与代码组成的可部署文件。`app.mjs`、`model.mjs`、`cloud.mjs`、样式和模板保存实现源码。`cloud/` 保存仅限本研究的数据库结构、分派方案和公开浏览器配置。材料来自 CUB-200-2011，保留其原有使用限制与图片权利；公开页面不为素材授予额外许可。

本仓库部署参与者网页，不公开研究答案键或数据分析文件。软件测试不能替代真人结果，也不证明论文结论或统计效能。
